# Security Policy

## Supported versions

Security fixes currently target the latest release on the default branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub private vulnerability reporting when it is enabled for the repository. Until a public remote exists, contact the repository owner privately.

Include the affected version, reproduction steps, impact, and any suggested mitigation. Do not include live credentials or personal data. Maintainers should acknowledge a complete report within seven days and coordinate disclosure after a fix is available.
