# Project Structure

| Path | Purpose |
|---|---|
| `src/domain.ts` | Provider-independent document and result types |
| `src/repository.ts` | Storage contract and in-memory adapter |
| `src/search-service.ts` | Search ranking and document retrieval logic |
| `src/server.ts` | MCP tool registration and stdio transport |
| `tests/` | Unit tests for application behavior |
| `docs/` | Public architecture decisions and roadmap |
| `.github/` | CI, dependency updates, and contribution templates |
